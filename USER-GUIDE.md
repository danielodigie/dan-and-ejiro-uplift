# Dan and Ejiro Uplift — User Guide (v1.0.3)

> A little encouragement can change your day. 3 minutes a day: morning message,
> afternoon rescue when needed, one-line evening reflection.

## 1. Get the app
- **Android:** download v1.0.3 from
  `https://github.com/danielodigie/dan-and-ejiro-uplift/releases/download/v1.0.3/uplift-v1.0.3-release.apk`
  → tap the file → allow install once → open.
- **iPhone or computer (no download):** open
  `https://dan-and-ejiro-uplift.netlify.app/` — or install it from box
  **8. Install the app** (Android: Install button; iPhone: Share → Add to Home Screen).

## 2. Create your account (pick one)
- **Email tab:** email + password (8+ characters) → Create account.
- **Phone tab:** phone number (`0803...` or `+234803...`) + password → Create phone account. No email needed.
- Already have one? Use **Sign in** (never create a second account — your
  streak, goals, and saves live on the first one).
- Locked out of email? **Forgot password?** → reset link → open it → new password → sign in.

## 3. The efficient daily routine (3 minutes)
1. **Morning — Home:** read *Today's Uplift*. **Like** teaches the app your
   taste; **Save** keeps it (pick a collection like *Difficult Days*); **New**
   shows another (never repeats within 7 days).
2. **Afternoon — I Need a Lift:** bad moment? Pick what you feel
   (discouraged, overwhelmed, lonely…) → optional situation → message + one
   10-minute action. This is the 2-tap rescue — the heart of the app.
3. **Evening — Check in + Journal:** log your mood (feeds your streak:
   *"Start again. Keep going."* — missing a day is never punished), write one
   line you're proud of, then open **Look How Far You've Come** to see victories.

## 4. Goals, Saved, Profile
- **Goals:** add what you're working toward; tap **Done** to celebrate.
  Turn any uplift into a goal with **Make Action**.
- **Journal → Saved tab:** every uplift you saved, by collection.
- **Profile:** change mood/situation/style anytime (future uplifts adapt);
  **Confidence Pack** (premium) → pay → 7-day journey, guided reflections,
  deeper insights.

## 5. Paying for Premium (₦1,500, test mode)
Profile → pack → **Pay with Paystack** → pay in the browser (test card
`4084 0840 8408 4081`, any future expiry/CVV) → come back → **I've paid —
Verify** → unlocked. Test mode = fake money, nothing real moves.

## 6. Troubleshooting (try in this order)
| You see | Do this |
|---|---|
| `unauthorized` / 401 errors | Sign out, sign back in (session expired). |
| `User already exists` (422) | You have an account — tap **Sign in**, not Sign up. |
| No photo on a message | Hard-refresh (Ctrl+F5) or close + reopen the tab/app. |
| Payment not confirmed | Finish paying in the browser first, then tap Verify again. |
| App stuck / blank | Close fully, reopen; check internet (login + fresh messages need it). |
| Anything else | Screenshot the exact red text + what you tapped → send to us. |
